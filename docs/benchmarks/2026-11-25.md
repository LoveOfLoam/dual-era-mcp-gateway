# Microbenchmarks

Local client/server load evidence is in
[`2026-11-25-local-load.md`](2026-11-25-local-load.md); it is not an Envoy/T8
benchmark. A real Envoy T8 run is in
[`2026-11-25-t8-load.md`](2026-11-25-t8-load.md). — 2026-11-25

**Scope:** in-process Go facade benchmarks. These are **not** Envoy/p99/500 RPS
numbers and must not be used as PRD NFR evidence.

## Command

```powershell
powershell -File scripts/bench.ps1
```

## Environment

- Windows 11, Go 1.26.4, 13th Gen Intel i7-13650HX
- `go test ./internal/facade -run '^$' -bench . -benchmem -benchtime=1s`
- Fake upstream (no network), 10 tools.

## Results

```text
BenchmarkToolsList-20    132280   10888 ns/op   10550 B/op   67 allocs/op
BenchmarkToolsCall-20     93070   12801 ns/op   10564 B/op  106 allocs/op
```

## Interpretation

- This measures facade JSON-RPC/validation/aggregation overhead only.
- It excludes Envoy, TLS, network, real upstream, auth/ratelimit RPCs.
- The PRD target (500 RPS, p99 gateway overhead < 10ms, 500 SSE) is **not**
  measured here. T8 + k6 are required for that claim.
